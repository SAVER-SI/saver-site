Why SAVER

Agents can pay autonomously.
They still need to know what to trust.

SAVER adds an independent verification layer between information and execution. It does not replace wallet policy, transaction simulation, or deterministic security controls. It answers a different question: is the factual premise supported by current evidence?

01

Independent second opinion

Verify a claim produced by another model, tool, API, or agent before relying on it.

02

Source-backed evidence

Receive structured output with evidence, cited sources, confidence, and explanation.

03

Native agent payments

Protected by x402 on Base Mainnet. No API key or manual billing integration required.

Integrate

One endpoint.
Built for software, not forms.

Send a claim to POST /verify. An unpaid request returns HTTP 402 with payment requirements. A compatible x402 client authorizes payment and retries.
