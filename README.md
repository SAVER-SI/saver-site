# SAVER Website

A polished static landing page for SAVER Verifier.

## Files

- `index.html`
- `styles.css`
- `app.js`
- `favicon.svg`

## Preview locally

From this folder:

```powershell
python -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Deploy

This is a dependency-free static site, so it can be deployed to:

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- Railway static hosting
- any normal web server
