A CHECKPOINT BEFORE PUBLICATION

One claim in.
Sources with the assessment.

  1. 01

    Select the material claim.

    Keep the exact figure, year, unit and qualification. Add the original source URL and definitions in context when available.

  2. 02

    Authorize one bounded check.

    Send JSON to POST /v2/verify. A valid unsigned request returns 402. An authorized x402 v2 wallet signs and retries under its existing spending policy.

  3. 03

    Inspect the evidence.

    Resolve each source ID, read the cited findings and distinguish supported, contradicted, mixed and unresolved material.

  4. 04

    Keep the scope explicit.

    Save the assessment and receipt with the selected claim. One checked claim does not certify an entire report.

DECIDE WITH THE RIGHT SCOPE

Know what the check buys.

When does claim verification help?

SAVER performs a separate research pass and returns cited findings. That can be useful for a material claim whose interpretation remains uncertain. If your existing workflow has already resolved the source and scope, reuse that evidence when adequate.

What does source verification cover?

Here, source verification means assessing whether web evidence supports a factual claim and its attribution. Use specialist tools for DOI existence and retraction checks, arithmetic, wallet risk and transaction simulation. SAVER is a factual-claim assessment, not an execution approval or a whole-report certification.

What does a completed check cost?

0.20 USDC on Base through x402 v2. A valid insufficient_evidence assessment is also a completed paid result. Reading the stored examples and inspecting discovery is free.

What if a response is lost?

Save an optional recovery token before the first request. Retained settled results can be recovered for 24 hours without a new payment. Do not blindly sign another payment after an uncertain outcome.
